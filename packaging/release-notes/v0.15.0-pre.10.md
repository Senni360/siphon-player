A clearer way forward when Spotify refuses the audio key.

This is a Windows x64 preview. On pre.3 or later, the app offers this update by itself. If you're new, or on an earlier preview, download it from https://siphon-friends.vercel.app, extract the whole zip and open `siphon.exe`. The executable is unsigned, so if Windows warns you, choose More info, then Run anyway.

## Better

- **The audio key error now leads somewhere.** When Spotify refuses the key, the banner offers Set up Soloist, which takes you straight to the steps.
- **Soloist setup is three clear steps,** with a Paste button for your key. You need your own Soloist key from Spotify, and Premium.
- **Shared files is in your library,** one click away from anywhere.
- Deleting a shared file or playlist now asks first, and the group won't store the same file twice.
