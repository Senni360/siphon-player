A song that will not play is skipped instead of stopping your music.

This is a Windows x64 preview. On pre.3 or later, the app offers this update by itself.

## Fixed

- **A song Spotify refuses no longer stops the playlist.** It is skipped like any other song that will not play, so a mixed playlist keeps going. Only a computer with no audio output at all still stops and shows how to fix it.
- **Three refusals in a row start a fresh Spotify session**, which is what a stale session needs, at most once a minute.
- **The phone skips a song it has no audio for** instead of asking. A dropped connection still retries the same song at the same place, so a tunnel does not make it skip.
- **The phone's Now Playing sheet is measured after it has risen**, so dragging the bar under the song seeks instead of missing it.
