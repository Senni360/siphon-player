This one fixes the crash. pre.18 closed itself a few seconds after start-up for anyone whose Home or queue met a beat whose description carried a hidden extra character - the zero-width spaces and curly quotes YouTube and SoundCloud descriptions are full of. Everything else in pre.18 is unchanged.

This is a Windows x64 preview. On pre.3 or later, the app offers this update by itself. If you're new, or on an earlier preview, download it from https://siphon-friends.vercel.app, extract the whole zip, and run `siphon.exe`.

## Fixed

- **The start-up crash.** Reading a beat's tempo and key from its description once walked the text two ways at the same time, and a multi-byte character in the wrong place cut one in half. The reading now walks the text one way, and a test feeds it the exact kind of description that crashed before.

## Good to know

- Every crash always followed the same path, reading the word "key" in a beat's description. If you saw Encore close itself with no message or banner in pre.18, this was it.
