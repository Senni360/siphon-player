Spotifast 0.13.0 plays on Google Cast speakers, checks the release signature before it installs an update, and comes to Windows as a Windows Installer package. It also speaks Ukrainian, opens upcoming albums, removes one song from the queue, draws its own title bar on Linux, goes easier on the battery, and fixes Sonos playback, resuming a paused playlist and much more. More than thirty people contributed to it.

## New

- **Play on Google Cast speakers and groups.** Cast speakers and speaker groups now appear in the device picker. Turn on local playback, pick the speaker, and Spotifast starts Spotify on it; from then on it plays like any other Spotify Connect device. Cast devices use certificates that your computer's trust store doesn't hold, so Spotifast accepts the certificate the device presents: whatever answers at the address of the speaker you pick on your local network receives a token issued for that speaker, not your reusable sign-in. See [Google Cast playback](https://spotifast.rocks/using-spotifast/#google-cast-playback) and [how it connects](https://spotifast.rocks/how-it-connects/#google-cast-devices). By @izadiegizabal. (#858)
- **Updates must carry the release's signature.** Spotifast now installs an update only when the release's `checksums.txt` has a valid Ed25519 signature from the Spotifast release key, then checks the download against it. A missing or wrong signature means no update. By @Josmar-o; thanks @realrandolph for the security audit that recommended it. (#836)
- **A Windows Installer package (`.msi`).** Antivirus engines kept flagging the old setup program, so Windows now gets a Windows Installer package for both x64 and ARM PCs. It installs for your user only, without an administrator password, like before. This release ships both:
  - for a new install, or to install by hand, pick the `.msi`; run over an existing Spotifast, it takes the installation over and keeps your settings, folder and Start menu entry, and Windows lists one Spotifast;
  - if you update from inside Spotifast, do nothing: 0.12.0 updates to this release through the setup program (`-setup.exe`), and from 0.13.0 on, updates move you to the `.msi` by themselves;
  - the next release ships only the `.msi`.



## Fixed

- **Playing a paused playlist resumes it.** The cards, sidebar cover and page header started a paused playlist over from its first song. By @YuEfSaEDU. (#657)
- **Sonos speakers play again.** Picking a Sonos speaker could fail with "receiver refused the connection". By @brandly; thanks @Aloe-recite and @elliotmartin. (#823, #612, #767)
- **Fewer "Spotify is rate limiting requests" errors.** Spotifast checks playback at most every 15 seconds instead of every 4. By @aw-snap. (#840)
- **Music keeps playing when the audio output changes,** such as when you plug in headphones. By @dennisgr7. (#731)
- **The resume point survives a dropped network or a sudden quit.** By @saikumargudelly and @dennisgr7. (#795, #793, #727)
- **Uninstalling on Windows while Spotifast runs no longer leaves half an install.** The uninstaller offers to close it first. By @samboland; thanks @AndrewDragonCh. (#766, #753)
- **A busy sign-in port is reported clearly,** before the browser opens. By @samboland; thanks @drewwells. (#768, #754)
- **The mini player opens on a connected display** after the screen it was on is gone, on macOS. By @HEOJUNFO; thanks @future10se. (#774, #719)
- **Song radio opened from a list is named after its song.** By @kevin9327; thanks @Slaurits. (#659, #644)
- **The Linux tray icon shows on Qt desktops such as KDE.** By @kevin9327; thanks @paganotoni. (#670, #660)
- **Dragging several songs within a playlist moves them** instead of adding copies. By @s6hib; thanks @jorisw. (#684, #669)
- **Sorting by album keeps each album's songs in track order.** By @SametKaras; thanks @sea2horses. (#701, #699)
- **A search typed with pauses leaves one Recent search,** not one for each pause. By @SametKaras; thanks @hpaliwal8. (#747, #741)
- **Playback artifacts are fixed, and a held volume slider responds.** By @samboland. (#686)
- **Closing a minimised window sends it to the tray** with Keep playing in the background on, instead of quitting. By @dennisgr7. (#725)
- **Playlist covers show when Spotify sends them as WebP, and library playlists the Web API leaves blank are filled in.** By @renaldypr. (#814, #813, #807)
- **Covers are drawn sharp** from copies scaled to the size they're shown, and use less memory. By @dennisgr7. (#866)
- **Colour from album art works on Liked Songs.** By @sasoder. (#750)
- **The Windows title bar buttons line up with the top bar** and react when pressed. By @samboland. (#742)
- **Small interface fixes:** the shuffle, saved and liked buttons stay green on hover, the search clear button is centred, playlist dialogs stay compact, side-by-side autoscroll areas no longer clash, and sign-in checks no longer keep the activity spinner busy. By @GoktugEk, @renaldypr, @ECuteri, @PixelAsh6 and @Iskrata. (#722, #822, #790, #855, #862, #797)
- **Better Turkish.** By @alikaanztrk. (#668)
- **Security updates.** rustls is updated for RUSTSEC-2026-0285, and chacha20 to 0.10.2. By @seichris and @Yaraill. (#743, #811) The saved sign-in token can no longer end up in debug output. By @DougNeo. (#756)
