Siphon 0.15.0-pre.2 adds optional Spotify Soloist playback. Open Settings → Spotify Soloist to download Spotify's player, save your personal key and pair it once in the Spotify app. The built-in player remains the default.

This is a Windows x64 preview. The portable executable is unsigned. Windows startup of Spotify Soloist 1.3.10.31 and its local control API were verified with a real key. Spotify app pairing and listening still need verification with your account. Cross-platform release checks are not complete.

## New

- **Play Spotify through Soloist.** Guided setup, protected key storage, account-verified device selection and renewal of expiring builds come from @crmne's Spotifast implementation ([crmne/spotifast#1050](https://github.com/crmne/spotifast/issues/1050), [crmne/spotifast#283](https://github.com/crmne/spotifast/issues/283)). Spotify Premium and a personal Soloist key are required. Soloist supports lossless playback, but does not report the delivered audio format.
- **Keep mixed-source playback.** Mixed playlists, SoundCloud and YouTube use Siphon's existing built-in player. Starting them turns Soloist off before handing over audio; your key remains saved. Start a Spotify-only collection before enabling Soloist again.

Soloist uses the system's default audio output. Siphon's EQ, local-file playback and full queue editing remain features of the built-in player. This preview does not include Spotifast's native audio capture adapters.
