Encore now finds its own permanent place the first time you open it.

This is a Windows x64 preview. On pre.3 or later, the app offers this update by itself. If you're new, or on an earlier preview, extract the whole zip and open `siphon.exe`. The executable is unsigned, so Windows may ask before running it.

## New

- **Encore moves itself out of Downloads.** A new copy opened from Downloads, or straight out of the zip, copies itself to `%LOCALAPPDATA%\Programs\Encore`, adds a Start menu entry and opens from there. You can delete the download afterwards.

## Good to know

Copies you already use stay where they are, along with their data. That includes one in Downloads, so if yours is there, move the whole folder yourself.

Opening a new download when Encore is already in that folder just opens the copy you have. To turn on music links, run `& "$env:LOCALAPPDATA\Programs\Encore\siphon.exe" --set-up-web-links` in PowerShell, then choose Encore for HTTP and HTTPS.
