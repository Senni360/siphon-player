WAV files can be shared now, and shared files say plainly when something's wrong.

This is a Windows x64 preview. On pre.3 or later, the app offers this update by itself. If you're new, or on an earlier preview, download it from https://siphon-friends.vercel.app, extract the whole zip and open `siphon.exe`. The executable is unsigned, so if Windows warns you, choose More info, then Run anyway.

## New

- **Share WAV files.** Bounces can go straight up to the group, up to the 40 MB limit. That's about 3 minutes 45 seconds of CD-quality WAV, so save longer tracks as MP3 or FLAC.

## Fixed

- **Apple Lossless files play.** They could be uploaded before but wouldn't play.
- **Clearer messages for shared files.** A duplicate, too many uploads in an hour, sharing turned off for you, and the monthly download limit now each say what happened. They used to say the service was down or busy.
- A friend's new shared file now lights up the Group badge.

## Good to know

A rare kind of MP3, variable bitrate with no length header, can stop before its real end. Re-saving the file fixes it.
